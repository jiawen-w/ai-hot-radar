# AI 热点雷达

每日自动扫描 30 个 AI 信息源，由 AI 判断哪些值得写、发在媒体上能不能火，输出带爆款潜力评分的选题清单。

## 页面功能

- **监测 30 个信源**：中文媒体 12 个、英文媒体 10 个、工具·论文·订阅 8 个
- **爆款潜力评分**：按 5 个维度（新奇度、大众相关性、情绪与争议、传播素材、多源热度）综合打分 0-100
- **选题分级**：S（≥85 值得立刻写）、A（70-84 值得跟进）、B（55-69 观察）
- **定时自动更新**：每 2 小时（7:00-21:00）由定时任务扫描信源、筛选热点、更新页面

## 本地文件

- `index.html` — GitHub Pages 入口（与 `AI热点雷达.html` 内容一致）
- `AI热点雷达.html` — 页面源文件
- `_shots/` — 页面自检截图产物（不纳入版本管理）
